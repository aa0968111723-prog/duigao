# WB03 真機驗收附錄（人類執行）

接續 `rounds/wb02/real-device-checklist.md` 的 5 項（判定規則同 —
CDP/模擬器證據不採計，需錄影）。WB03 追加 4 項：

| # | 項目 | 操作 | 通過標準 |
|---|------|------|----------|
| 6 | 手指繪圖 | 繪圖工具開 → 手指畫 3 筆（含快速塗鴉） | 每筆成一個節點、線條跟手（無明顯遲滯）、第二指落下時當前筆畫取消並進入縮放 |
| 7 | frame 拖曳 | 建立區塊 → 拖標題列 | frame＋框內節點一起動、放手不跳回、undo 一次復原 frame 位置 |
| 8 | 來源訊息跳回 | 討論訊息「加入白板」→ 板上選該節點 →「打開來源訊息」 | 回到討論、原訊息置中並閃黃 1.6 秒 |
| 9 | overlay back | 板上開文宣「打開內容」→ 按系統返回 | overlay 關、白板還在（不退回板清單）；再按返回才退板 |

- 裝置：同 wb02（Android Chrome＋iPhone Safari 各一）。
- 項 6 是 ADR-013 checkpoint 第 5 項（60fps 拖曳）的延伸 — 繪圖遲滯
  明顯即記 FAIL。
- 全過標準與 xyflow spike 條款沿用 wb02 檢查點（一次 7 天修復窗）。
