# 對稿 · 團隊文宣修改指示

把 Canva / Adobe 做好的活動海報，變成一條連結傳給夥伴一起對稿。團隊成員**不直接修改原稿**，只要指出哪裡需要改、問題是什麼、建議怎麼改，設計者就能照著清單逐項處理。

## 核心原則

> 只標記，不改原稿。

這個工具不是另一套 Canva，而是把「這裡怪怪的」變成設計者看得懂、做得完的修改指示。

## 功能

- 上傳海報（可多版本：初稿、改一…）
- 彩色 / 黑白 / 左右對切預覽
- 版本並排、滑動比對
- 圖上建立「修改點」與塗鴉圈選
- 修改點自動編號
- 問題分類：文字 / 排版 / 圖片 / 顏色 / 資訊錯誤 / 其他
- 優先程度：一般 / 重要 / 急
- 分開記錄「哪裡有問題」與「建議怎麼改」
- 待修改 / 已完成 / 重新開啟
- 一鍵整理並複製完整修改清單
- 一鍵傳到 LINE
- 同一連結多人同時看（WebRTC / PeerJS）

## 使用

1. 打開網站，上傳活動海報
2. 按「建立連結」分享給團隊
3. 夥伴用手機打開並輸入名字
4. 用「修改點」直接點在需要調整的位置
5. 選問題類型與優先程度
6. 填寫問題，以及建議怎麼改
7. 設計者修改後將該項標記為「完成」
8. 必要時複製完整修改清單貼到 LINE 或其他群組

> 海報資料存在瀏覽器（IndexedDB）。主辦方請先打開自己的連結；若夥伴顯示找不到，請主辦再打開一次以同步。

## 本機開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

輸出在 `dist/`，可部署到 Vercel 或 GitHub Pages。

## 部署到 Vercel

1. 打開 [vercel.com/new](https://vercel.com/new)
2. Import 這個 GitHub repo：`aa0968111723-prog/duigao`
3. Framework Preset 選 Vite，直接 Deploy
4. 得到網址後即可使用

## 技術

- Vite + React + TypeScript
- IndexedDB 本地儲存
- PeerJS（WebRTC）多人同步
