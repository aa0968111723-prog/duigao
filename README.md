# 文宣討論區

一個**手機優先**的團隊文宣討論工具。把 Canva / Adobe 做好的活動海報變成一條連結傳給夥伴，大家不直接修改原稿，只需要指出哪裡要調整、問題是什麼、建議怎麼改。

## 核心原則

> 海報是主畫面，討論要比編輯更快。

這不是另一套 Canva，而是讓團隊在手機上就能把「這裡怪怪的」變成清楚、可執行的修改指示。

## 手機版操作重點

- 海報盡量佔滿主畫面
- 底部固定拇指工具列：看 / 修改點 / 圈畫 / 擦掉
- 版本列可左右滑動切換初稿、改一、改二…
- 修改點在海報上縮成編號圖釘，避免擋住設計
- 新增修改點改成 Bottom Sheet，方便單手輸入
- 修改清單 / 聊天平常只露底部入口，點擊後往上展開
- 分享視窗改成手機 Bottom Sheet
- 支援 safe-area，適合瀏海與全螢幕手機
- 手機主流程簡化，進階彩色 / 黑白 / 對切 / 並排 / 滑動比較保留於平板與桌機

## 既有功能

- 上傳海報（可多版本：初稿、改一…）
- 圖上建立「修改點」與圈畫
- 修改點自動編號
- 問題分類：文字 / 排版 / 圖片 / 顏色 / 資訊錯誤 / 其他
- 優先程度：一般 / 重要 / 急
- 分開記錄「哪裡有問題」與「建議怎麼改」
- 待修改 / 已完成 / 重新開啟
- 一鍵整理並複製完整修改清單
- 一鍵傳到 LINE
- 同一連結多人同時看（WebRTC / PeerJS）
- 平板 / 桌機保留彩色、黑白、對切、並排與滑動比對

## 使用

1. 打開「文宣討論區」並上傳活動海報
2. 按「分享」把連結傳給團隊
3. 夥伴用手機打開並輸入名字
4. 底部選「修改點」，直接點海報需要調整的位置
5. 在 Bottom Sheet 填問題類型、問題與建議
6. 從底部「修改點」面板查看待修改清單
7. 設計者修改後將項目標記完成

> 海報資料目前存在瀏覽器（IndexedDB）。主辦方請先打開自己的連結；若夥伴顯示找不到，請主辦再打開一次以同步。

## 本機開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

輸出在 `dist/`，可部署到 Vercel 或 GitHub Pages。

## 技術

- Vite + React + TypeScript
- IndexedDB 本地儲存
- PeerJS（WebRTC）多人同步
- Mobile-first CSS override
